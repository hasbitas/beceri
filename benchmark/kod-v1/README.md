# kod-v1

75 Python programlama görevi: 60 tek dosyalı, 15 çok dosyalı. Her görevde bir
doğal dil tanımı (`task.json`), doğru bir başvuru çözümü (`gold/`), bilerek hatalı
bir çözüm (`broken/`) ve görünür/gizli test dosyaları (`tests_visible/`,
`tests_hidden/`) bulunur. Bölümler `split.json` içinde (development / selection /
final, 25'er görev); dosya özetleri `SHA256SUMS` içindedir.

Biçim, çalıştırma, görev ekleme ve kaynak notu: `docs/BENCHMARK.md`.

75 Python programming tasks (60 single-file, 15 multi-file) with a reference
solution, a deliberately broken solution and visible/hidden tests per task.
See `docs/BENCHMARK.md`.
